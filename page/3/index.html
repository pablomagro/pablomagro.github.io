Kubernetes

Kubernetes Notes

Kubernetes is an open-source platform for automating the deployment, scaling, and management of containerized applications.

  1. Kubernetes is a tool for running a bunch of different containers.
  2. We give it some configuration to describe how we want our containers to run and interact with each other.

What? System for running many different type of containers over multiple different virtual machines.

Why? When you need scale an app to run many different containers with different images.

AI App Builders

  • v0 by Vercel: AI-powered web development platform that turns prompts into working full-stack apps, with one-click Vercel deployment and GitHub integration. Great for fast prototyping, less suited for complex production codebases without cleanup. v0
  • Atoms (by MetaGPT): Multi-agent platform aiming to take an idea all the way to a “profitable business” - UI, workflows, and deployment included. Evolved from the MetaGPT open-source framework and MGX. Interesting but still early; treat “ready to turn a profit” claims with skepticism. Atoms

AI Chat & Agents

  • Flowith: Self-described “Agentic Workspace” for running AI agents on tasks. Documentation is sparse, so maturity is hard to judge - worth a quick trial before committing. Flowith
  • Msty: Privacy-focused AI ecosystem with four components - Studio (private chat workspace), Go (bounded task agents), Nexus (model/credential gateway), and Stack (governed knowledge layer). Aimed at teams needing SSO, audit logs, and zero telemetry. Recommended if you need multi-model flexibility with real governance controls. Msty

Install additional plugins

hexo-renderer-marked

The hexo marked renderer is a markdown rendering engine that enables you to configure how your markdown should be processed. The module follows commonmark specs as much as possible.

More info: Rendered Marked

Installation

Options

You can configure this plugin in _config.yml.

hexo-generator-category

If you like, you can include a page for every category you use on your weblog. Add a property to your markdown files that specify in which category the post belongs and install this module to generate a page for that category.

Installation

Options

You can configure this plugin in _config.yml.

hexo-generator-tag

You can select a tag and go to a page listing all the posts that are tagged with that particular tag. The hexo-generator-tag module is required for this functionality, so I suggest you install this if you like to enable people to browse your site by tag.
